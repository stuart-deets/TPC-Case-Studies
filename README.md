# Description
This repository is meant to store case studies and scenarios for teaching a technical & professional communication class. 
These are meant to be printed out and completed by students in-class. Minis should take around 15-20 minutes to complete. Some students may take less time.
The scenarios are meant to be challenging and difficult. 
The scenarios are meant to draw on common learning concepts in TPC courses such as rhetoric, ethics, and how to write instructions. 
Use the pull request function to add your own scenarios. Effective scenarios should be:
1. Quick, short, and low stakes
2. Relate to class material in TPC
3. Relate to core learning outcomes
4. Be designed to be completed in 15-20 minutes in class, on paper, with no additional information besides what's included in the scenario
